# Tip Calculator

A simple tip calculator and bill splitter web app.

## How to Run

Just open the `index.html` file in any browser. No install needed.

If you want to run it with VS Code, install the Live Server extension, then right-click `index.html` and click "Open with Live Server".

## Features

- Enter a bill amount and it calculates the tip automatically
- Choose from 10%, 15%, 20% tip or enter a custom percentage
- Split the bill between multiple people
- Shows tip amount, total, and per person share
- Error messages show up if you enter wrong values
- Reset button to start over
